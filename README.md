# Aqarmap Real Estate Web Scraper & Automation

An automated web scraping pipeline built with **Python**, **Selenium**, **BeautifulSoup**, and **Pandas** designed to harvest real estate listings and property data efficiently.

## Features
- Automatically navigates property portals, handles dynamic loading, and extracts detailed real estate listings.
- Parses structured data including property prices, locations, specifications, and details.
- Exports extracted data seamlessly into CSV formats (`properties-details.csv` / `sales.py`) for market analysis and data processing.

## Tech Stack
- **Language:** Python
- **Automation & Parsing:** Selenium, BeautifulSoup
- **Data Manipulation:** Pandas
- **Output Data:** CSV / Structured Files
